# МФК «Доза Агро» — Контекст проекта и архитектурная память (Project Context)

> Документ создан для мгновенной синхронизации любого сеанса разработки и ИИ-ассистента с текущим состоянием проекта, всеми принятыми решениями, дизайн-системой и историей правок.

---

## 1. Общие сведения о проекте
- **Суть:** Официальный веб-портал мини-футбольного клуба «Доза Агро» (Нижний Новгород), выступающего в Первой лиге Чемпионата города по мини-футболу (футзалу) сезона 2026/2027 (Департамент физической культуры и спорта / Наградион).
- **Репозиторий:** `https://github.com/AL-Lisov/mini-football.git` (ветка `main` — веб-портал, ветка `smm` — медиа-материалы и посты).
- **Production (GitHub Pages):** `https://al-lisov.github.io/mini-football/`
- **Локальный Dev-сервер:** `http://localhost:3000` (запускается через `python -m http.server 3000` в корне проекта).

---

## 2. Стек и архитектура файлов
- **HTML5:** `index.html` — семантическая разметка, чередующиеся блоки, единый хедер, модальные окна, схемы.
- **CSS3:** `styles.css` — кастомная дизайн-система (без тяжелых внешних фреймворков), CSS-переменные, адаптивность (десктоп, планшет, мобильные).
- **JavaScript (ES6+):** 
  - `data.js` — локальная база данных (состав из 18 игроков, матчи, турнирная таблица, статистика вратарей, контакты руководства).
  - `app.js` — логика интерфейса (ScrollSpy активного пункта навигации, фильтры амплуа, интерактивная тактическая доска 5х5, полноэкранный просмотр фото, экспорт в `.ics`).
- **Графика и медиа:**
  - `img/balashov_dark_hero.jpg` — промо-визуал тренера/капитана Максима Балашова (#17) в правом блоке Hero.
  - `shields/` — векторные и растровые эмблемы всех клубов Первой лиги.

## 3. Ключевые дизайн-принципы и жесткие правила

1. **Эстетика Bianconeri (Juventus-стиль):**
   - Контрастное чередование темных (`#0a0b0e`) и светлых/нейтральных секций.
   - Премиальная спортивная типографика (шрифты `Unbounded`, `Inter`, `JetBrains Mono`).
   - Акцентный цвет: **Neon Volt** (`#ccff00` / `var(--neon-volt)`) для активных пилюль навигации, бейджей и статусов.
   - Разделители между информационными карточками (например, в блоках лидеров) выполнены в контрастном белом цвете.

2. **СТРОГО БЕЗ ЭМОДЗИ (Zero Emojis):**
   - Во всех файлах проекта (HTML, CSS, JS, текстах) категорически запрещены эмодзи. Используются строгие типографические символы, бейджи или SVG-иконки.

3. **Единая шапка и навигация (ScrollSpy):**
   - Отдельная дублирующая полоса подменю убрана. Все разделы (`О клубе`, `Матч-центр`, `Состав`, `Тактика`, `Таблица`, `Календарь`, `Наградион`) находятся прямо в верхнем фиксированном хедере `.site-header`.
   - Активный раздел подсвечивается неоново-желтой плашкой (`.nav-link.active`) автоматически при прокрутке экрана через IntersectionObserver/ScrollSpy.

4. **Единые размеры портретов игроков:**
   - Все фотографии игроков в карточках состава (`.fut-portrait-wrap`, `.fut-player-img`, `.fut-initials-fallback`) стандартизированы под точный размер **120x120px** с `object-fit: cover` и `border-radius: var(--radius-md)`. Никакого разнобоя по высоте/ширине.

5. **Hero-блок без лишнего визуального шума:**
   - Фоновый водяной знак (`DOZA AGRO 2026`) полностью удален — он не создавал пользы, обрезался карточками и выглядел как артефакт. Фон оставлен чистым глубоким черным.
   - Справа расположен стилизованный визуал с Максимом Балашовым и аккуратным бейджем игрока/тренера.

## 4. Структура разделов страницы
1. `#section-hero` — «О клубе»: герб, руководство (Павлюк Александр, Балашов Максим), фото Балашова, 4 метрики сезона (18 игроков, 1 место в таблице, 0 пропущенных, 100% надежность).
2. `#section-matches` — «Матч-центр»: последние и предстоящие матчи, счет, составы, статистика.
3. `#section-squad` — «Состав»: фильтрация по позициям (Вратари, Защитники, Универсалы, Нападающие), карточки игроков с детальной статистикой.
4. `#section-tactics` — «Тактика»: интерактивное поле 5х5 с расстановкой игроков и кликабельными позициями.
5. `#section-standings` — «Таблица»: турнирная таблица Первой лиги с эмблемами команд, зонами медалей и формой.
6. `#section-calendar` — «Календарь»: полное расписание сезона с датами, залами и кнопкой экспорта в календарь.
