# МФК «Доза Агро» (Нижний Новгород) — Официальный веб-портал

Официальный веб-сайт мини-футбольного клуба **«Доза Агро»** (Чемпионат города Нижнего Новгорода по футзалу / Первая лига 2026/2027, Департамент физической культуры и спорта / Наградион).

## 🚀 Основные возможности
- **Состав команды:** подробные карточки игроков, амплуа, игровые номера, возраст, статистика.
- **Вратарская статистика:** учет пропущенных голов, матчей «на ноль» (clean sheets), 6-метровых (пенальти) и 10-метровых (дабл-пенальти).
- **Календарь и результаты:** результаты завершенных матчей с отметками о таймах и «сухих» играх, протоколы, расписание предстоящих игр.
- **Турнирная таблица:** автоматический учет побед, ничьих, поражений, разницы забитых/пропущенных мячей и очков с формой команды (W/D/L).
- **Тактическая схема 5х5:** интерактивная расстановка на футзальном паркете с быстрым переходом в досье игроков.
- **Экспорт в календарь:** загрузка файла `.ics` для добавления матчей в Apple Calendar / Google Calendar.
- **Галерея в высоком разрешении:** просмотр фотографий игроков, руководства и командного фото в полноэкранном лайтбоксе.
- **Фоновые темы:** выбор между классическим фоном ННДЕПСПОРТ, обновленным лазурным и глубоким синим.

## 🛠 Стек технологий
- Чистый HTML5, Vanilla CSS3 (дизайн-система в стиле T-Bank UI + регламент Суперлиги по футзалу).
- Vanilla JavaScript (ES6+), локальная база `data.js` / `site_data.json`.
- Полная адаптивность: Desktop, планшеты, мобильные устройства.

## 📦 Быстрый запуск локально
```bash
python -m http.server 3000
# или npx serve .
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.
