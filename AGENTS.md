# Инструкции и правила для ИИ-ассистента (AGENTS.md)

При работе с проектом веб-портала **МФК «Доза Агро»** соблюдайте следующие правила:

1. **Контекст проекта:**
   - Перед внесением изменений ознакомьтесь с [PROJECT_CONTEXT.md](file:///d:/projects/Antigravity%20IDE/mini-footbal/PROJECT_CONTEXT.md) — там описана вся архитектура, история решений и структура данных.

2. **Строгий запрет эмодзи:**
   - Никаких эмодзи в коде, стилях, разметке и данных (`index.html`, `styles.css`, `app.js`, `data.js`). Используйте строгую типографику и SVG.

3. **Стиль и палитра:**
   - Эстетика Bianconeri (контрастные темные/светлые блоки в стиле Juventus).
   - Акцентный цвет: Neon Volt (`#ccff00`).
   - Белые разделители между блоками карточек лидеров.

4. **Верстка и стандарты:**
   - Портреты игроков в `.fut-portrait-wrap` строго **120x120px** с `object-fit: cover`.
   - Навигация: единый хедер `.site-header` со ScrollSpy (`.nav-link.active`). Без дублирующих подменю.
   - Фоновые водяные знаки в Hero не использовать — фон должен быть чистым.

5. **Контроль версий:**
   - После завершения задач коммитить и пушить в `main` на GitHub (`https://github.com/AL-Lisov/mini-football.git`), так как продакшн развернут на GitHub Pages.
